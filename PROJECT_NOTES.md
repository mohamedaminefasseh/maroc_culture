# Project notes

This version avoids the previous blank/green map issue by using a simpler Leaflet setup similar to the original uploaded HTML code.

Main map stack:

- Leaflet JS
- OpenStreetMap tile layer
- Carto Voyager optional layer
- Esri World Street optional layer

Because some school/company networks block map tile providers, a Google Maps iframe fallback is added. It does not need a Google API key.

Destinations marked:

- Marrakech — Jemaa el-Fna Square
- Casablanca — Hassan II Mosque
- Fes — Chouara Tannery
- Chefchaouen — Chefchaouen Medina
- Merzouga — Erg Chebbi dunes
- Essaouira — Essaouira Port
- Rabat — Hassan Tower
- Tangier — Tangier Kasbah area
- Aït Ben Haddou — Ksar of Aït Ben Haddou
